# Tech stack & conventions

- **Runtime:** Node.js ≥ 20 (CI and verification run on 22).
- **App:** Next.js 16 App Router, React 19, TypeScript strict. Plain CSS in
  `app/globals.css` (no Tailwind) — design tokens are CSS variables.
- **Engine:** pure TypeScript in `engine/`, no framework imports, usable from
  the Next.js route, the CLI and the browser (`engine/apply.ts`,
  `engine/report.ts` must stay browser-safe).
- **Parsing:** `@babel/parser` with `errorRecovery`; edits via `magic-string`
  so untouched code keeps its original formatting byte-for-byte.
- **Diffs:** `diff` (jsdiff). **Zips:** `fflate`.
- **Tests:** `node:test` everywhere. Engine tests: `npm test`. Generated
  suites are CommonJS `.cjs` so they run inside legacy CJS packages.

## Rules

- Never introduce a dependency into a resurrected tree without a row in
  `INTRODUCED` (engine/knowledge.ts) explaining why.
- Every codemod rule lives in `RULES` with a title and severity; every edit
  goes through `safe()` so overlapping edits degrade to a flagged finding
  instead of throwing.
- Registry access goes through a `RegistryLookup` so tests can use
  `snapshotRegistry()` offline.
- `data/presets/*.json` is generated by `npm run necro:verify`. Do not edit by
  hand; re-run the script after touching the engine or a specimen.
